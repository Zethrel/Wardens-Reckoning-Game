# Prototype pictures (v0.2, 14-11-2026)

The first pictures, for the asset preview only (`src/UI/AssetPreview.tscn`).
The game does not use them yet. 32 pixels a tile:

- `surfaces/`: grass and rough ground, four variants each, 32 × 32.
- `things/`: `tree_01` and `tree_02`, 32 × 64, the trunk's foot at (16, 63).
- `colonists/`: one colonist standing, facing down, in three layers of 32 × 48
  (`base`, `clothing`, `hair`, drawn in that order), the feet at (16, 46).

The whole package, its manifest and the reviews are kept with the
implementation planning (`03 - Asset Prototypes`), not here.
