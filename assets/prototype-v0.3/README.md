# Vegetation prototype (v0.3, 14-11-2026)

Ten trees, a second set to compare with v0.2's in the asset preview
(`src/UI/AssetPreview.tscn`: T switches, V the variant, Y the age). The game
does not use them.

- `tree_mature_deciduous_<green_01|green_02|autumn_01|winter_01>`: 64 × 96.
- `tree_mature_conifer_<01|02>`: 32 × 96.
- `tree_young_<deciduous|conifer>_01`: 32 × 64.
- `tree_sapling_<deciduous|conifer>_01`: 32 × 32.

Not cleaned for production: see the review of v0.3 for the defects found (the
whole package and its reviews are kept with the implementation planning,
`03 - Asset Prototypes`).
